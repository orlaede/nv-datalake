# Kestra Implementation Plan

**Goal:** Executar e testar o pipeline completo Bronze → dbt usando Kestra.

**Architecture:** Carregador Bronze compartilhado com Dagster; Kestra com Process
runner e cópia dbt por execução; PostgreSQL exclusivo para metadados.

**Tech Stack:** Kestra 1.3.41, PostgreSQL, Python, SQLAlchemy, pandas, dbt-postgres.
